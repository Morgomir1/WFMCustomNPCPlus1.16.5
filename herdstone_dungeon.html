Камень Расколотого Рога

Логово мятежного стада в Драквальде из четырёх локаций: Гнилая просека, Осквернённая крипта, Корневые глубины и Провал Камня Стада. Каждая локация заканчивается ареной с боссом, и только через неё можно пройти дальше. Вход один, выход один, после последнего босса. Стадо враждебно и Порядку, и Разрушению, поэтому все квесты внутри данжа одинаковые для обеих сторон.

Лор

Где. Драквальд — тёмный лес между Мидденхеймом и Мидденландом, когда-то провинция Империи, а теперь охотничьи угодья стад Казрака Одноглазого. В чаще стоят руины монастыря Зигмара времён старой провинции.

Что случилось. Под руинами Стадо Расколотого Рога нашло обломок чёрного камня с прожилками варпа и сделало из него Камень Стада. Его вожак, думбулл Гарракс, решил, что Камень даст ему силу стать Повелителем Зверей. Он не стал склонять рога ни перед Казраком, ни перед вестниками Тёмных Богов. На Гехаймниснахт, Ночь Тайн, Гарракс хочет накормить Камень кровью, чтобы тот породил новых минотавров.

Почему это касается обеих сторон. Гарракс убивает всех, кто входит в чащу: людей, гномов, орков, чужие стада, избранных Хаоса. Сытый Камень даст ему армию, против которой не устоит ни Порядок, ни Разрушение. Поэтому внутри данжа цели у сторон одни и те же: убить Гарракса и его вожаков и сорвать обряд. Различаются только слова, которыми лагеря об этом говорят.

Монастырь, стадо и имена боссов придуманы для данжа. Драквальд, Казрак, Гехаймниснахт и все типы существ — каноничные.

Правила данжа

Один входВрата черепов на южной границе просеки. Граница — терновый декор и ряд minecraft:barrier. Барьер ставится один раз при постройке и больше не трогается. Отдельной «невидимой стены» в CNPC нет.
Один выходПодъём Висельника закрыт барьером. Его снимает died Гарракса и возвращает init Гарракса при возрождении. Снаружи в выход не войти.
Арены — шлюзыПроход в следующую локацию начинается в арене босса. Ворота открывает died босса и закрывает его init: CNPC вызывает init при каждом возрождении NPC.
Респаун 1 часВстроенный Respawn 3600 у всех мобов и боссов. Таймер считается в реальном времени и хранится в NBT NPC, а возрождение происходит при загрузке чанка. Поэтому не нужны ни /forceload, ни NPC-смотритель.
Головоломки закрываются самиКаждый Scripted Block, который что-то открыл, через час в своём tick возвращает блоки на место. Если рядом стоит игрок, закрытие откладывается. Блок тикает только в загруженном чанке, а чанк загружен, только когда рядом есть игроки, — то есть именно тогда, когда сброс кому-то нужен.
Нет глобального состоянияСостояние хранится на самом боссе или блоке (storeddata) либо в world.getTempdata() для коротких последовательностей. Ключей в world storeddata, которые надо кому-то обнулять, нет.
Шорткаты не обходят боссовВсе шорткаты ведут внутри одной локации: от прихожей арены назад к началу локации. Срезают мобов и головоломки, но не арены.
Квесты универсальныеНи одна механика внутри данжа не привязана к фракции. Задания одни и те же, лагеря выдают их через разных NPC.

Лагеря и квесты

Оба лагеря стоят снаружи, на опушке у южной границы, по разные стороны от Перекрёстка. От Перекрёстка ведёт тропа к Вратам черепов. PvP между сторонами — настройка сервера, не CNPC. Лагеря бьют чужаков через фракции (Attack hostile factions) и дальность агро в Stats.

ПОРЯДОК

Застава Волчьего Брода

Юго-западная опушка. Квестодатель — Отто Рейнхардт (Dialog + Quest). Рядом NPC с ролью Trader (магазин). Кузнец — обычный NPC без роли, только декор и реплика. Респаун: в interact Отто вызывает player.setSpawnpoint(x, y, z) на кровать заставы.

«Если Камень наестся, к весне эта чаща дойдёт до стен Мидденхейма».

РАЗРУШЕНИЕ

Чёрный круг

Юго-восточная опушка. Квестодатель — Гурхак (тот же квест, другой диалог). Рядом Trader своей фракции. Респаун: setSpawnpoint в interact Гурхака.

«Гарракс забыл, кому служит. Принеси его рога — и Камень снова будет служить сильным».

В Global → Quests заведи один квест на цель (Type: Area Kill, имя цели = имя Display босса, например «Грул Кабанья Рука»). Area Kill засчитывает убийство всем игрокам с активным квестом в 10 блоках от цели; обычный Kill — только добившему. В диалоге Отто и в диалоге Гурхака укажи этот же квест (Dialog → Quest). Повтор: в карточке квеста включи Repeatable, если нужно ходить после каждого респауна босса.

Вертикальный разрез

Сплошная линия — маршрут. Красные ромбы — арены, через которые лежит переход между локациями. Бирюзовый пунктир — шорткаты, все внутри своих локаций. Чёрный пунктир — единственный выход.

Масштаб планов: терновая рамка локации 1 = 350×247 блоков (длинная сторона 350). Тонкая сетка — 10 блоков, жирная — 50. Остальные этажи в том же масштабе. Разрез схематичный (Y слоёв ориентировочно 64–80 / 44–60 / 24–40 / 4–20).

B2 Головоломка: три вентиля

Вода в зале — статичный декор. Проходы к B3 и B4 закрыты тремя завалами из полных блоков. Три Scripted Block (V1, V2, V3), в скрипте каждого константа ID = 1/2/3. ПКМ дописывает ID в world.getTempdata() ключ hs_valves. Порядок 2 → 1 → 3 (подсказка на табличках-надгробиях). Верный шаг: removeBlock своего завала (5–8 координат). Неверный: очистить hs_valves, вернуть все завалы, spawnClone «Гор (призыв)» ×2. V1 в своём tick через час после последнего открытия ставит все три завала обратно (если рядом нет игроков) и очищает hs_valves. Слив зала водой в CNPC не делается.

B3 Головоломка: тотемы Тёмных Богов

Четыре Scripted Block, в скрипте каждого константа N = 1…4. ПКМ крутит знак по кругу K → N → T → S, пишет его в world.getTempdata() ключ hs_god_N и сообщает игроку текущий знак. Подсказка — таблички или кафедра с книгой у входа (порядок богов в молитве = ответ). Когда все четыре ключа совпали с кодом — снять блоки реликвария. Внутри тайник с Тотемным амулетом. Тотем №1 в своём tick через час закрывает реликварий и очищает ключи.

B4 Притвор: Шкрик

NPC Шкрик, фракция «Нейтралы данжа», Role нет, Dialog включён. Опция «накормить» видна всегда. В dialogOption (проверка e.option.getName()): найти в инвентаре стак с именем «Гнилой окорок» циклом по слотам. Нет — say «Пусто в лапах — пусто в ответе». Есть — уменьшить стак на 1, say подсказки, снять завал S2 и записать себе в storeddata время закрытия. tick Шкрика (идёт и у мёртвого NPC) через час ставит завал обратно. Убить Шкрика — обычная смерть, респаун 3600. Запасной рычаг S2 — самозакрывающийся Scripted Block в B1 на тех же координатах.

Локация 3 · Корневые глубины

Земляные пещеры, сквозь которые идут корни толщиной с дом: dark oak wood, мицелий, шрумлайты, костные блоки. Чем ниже, тем больше зелёного свечения варпа. Локация про ритм, выживание в тумане и большую арену. Вход из арены Б2, выход через арену Б3.

C2 Головоломка: зов стада

Четыре Scripted Block-барабана, в скрипте каждого константа KEY = L/R/B. Барабан звучит, только если у игрока в главной руке «Рог Бра-шамана» (кость с именем, дроп Б2); иначе — сообщение «Барабан глухо молчит». Ритм за 6 с (120 тиков): L L R B, последовательность в world.getTempdata(). Ошибка — spawnClone «Унгор (призыв)» ×3 (на них тот же скрипт маски, что у вышек). Успех — снять завал ворот. Левый барабан в своём tick через час ставит завал обратно.

C3 Варп-топь

Скрытый Scripted Block «Туман» под полом топи. В tick (каждые 10 тиков): игроки в кубе ±16 блоков (getNearbyEntities ищет по кубу, не по сфере). Если у игрока storeddata hs_clean_until ещё не истёк — пропуск. Иначе addPotionEffect тошнота (PotionEffectType_NAUSEA) 3 с и иссушение 2 с (длительность в секундах). Четыре Scripted Block «святая трава»: ПКМ пишет игроку hs_clean_until = now + 300 тиков. Зона урона мода здесь не используется: она не умеет пропускать «чистых» игроков.

D1 Пиршество минотавров

Четыре минотавра (имя «Минотавр»), в init — On Attack = Ничего (setRetaliateType(3)): цель они видят, но стоят и пируют. Состояние у каждого своё, без world storeddata. Проснуться (setRetaliateType(0) всем четырём, поиск по имени в радиусе 30 + isAlive()) они могут тремя путями:

  • Бой — игрок ударил любого: damaged будит всех.
  • Подход — в tick минотавра: игрок ближе 6 блоков к столу (дистанция считается вручную). Балка под потолком (паркур, без скрипта) проходит выше этого радиуса.
  • Окорок со стола — тайник на столе выдаёт «Гнилой окорок» и пишет в world.getTempdata() hs_feast_wake_at = now + 400 тиков. Минотавры просыпаются через 20 с — успей уйти.

Засыпают обратно сами: в tick, если цели нет и игроков в радиусе 32 нет, — снова setRetaliateType(3). Добыча — дроп в Inventory NPC.

D2 Круг Вызова

Восемь бестигоров во фракции «Нейтралы данжа»: NPC враждебной фракции диалог не откроет. Чемпион — отдельный клон «Чемпион Круга» с Dialog «Право Вызова». Опция «принять» (dialogOption): поставить кольцо minecraft:barrier по списку координат, чемпиону setFaction(id Стада) и On Attack = Мстить. Остальные семь не трогаем — они нейтральны и стоят. died чемпиона: снять кольцо и записать в world.getTempdata() hs_d2_won_until = now + 72000. Опция «отказаться» или удар по любому из восьми (damaged): всем восьми setFaction Стада, кольцо не ставится. init каждого бестигора (возрождение) возвращает фракцию «Нейтралы данжа». Если группа проиграла или ушла: в tick бестигора без цели и без игроков в радиусе 32 — вернуть нейтральную фракцию; чемпион при этом ещё и снимает кольцо. Scripted Block S4 открывает люк, только пока не истёк hs_d2_won_until.

Боссы

Цифры на 2–3 игроков в железе/алмазе; для соло делите HP на 1,6. Каждый босс — NPC в клонере, Stats → Respawn 3600, AI → Return to start = да (чтобы возрождался в арене после setPosition), фракция «Стадо Расколотого Рога». Модель — Display этой сборки (GeckoLib Custom Model). Вкладка Scripts: init/tick/died/damaged. Абилки мода: dash, jump_slam, weapon_spin через AbilityAPI.start. tick CNPC вызывает и у мёртвого NPC, а init — ещё и при первом событии после рестарта или /script reload, поэтому оба начинаются с if (!npc.isAlive()) return;. Все флаги фаз обнуляются в init.

Шорткаты

Все шорткаты открываются изнутри и закрываются сами через час. Каждый ведёт от прихожей арены назад к началу той же локации. Если группа погибла на боссе, она возвращается к арене через срезку и не зачищает локацию заново. Предыдущие арены по пути при этом пусты, пока не прошёл час.

Как собрать это в CustomNPC+

Ниже только то, что ставится руками в GUI и скриптах этой сборки. Скрипты — Nashorn: var и function, storeddata только строками. В начале файла: var NpcAPI = Java.type("noppes.npcs.api.NpcAPI").Instance(); и при необходимости EntitiesType, AbilityAPI. Командные блоки, /fill и /effect не нужны.

1. Фракции (Global → Factions)

  1. Порядок — дружественна игрокам Порядка, враждебна Разрушению и Стаду.
  2. Разрушение — наоборот.
  3. Стадо Расколотого Рога — враждебна обеим. Все мобы и боссы данжа.
  4. Нейтралы данжа — Шкрик и бестигоры Круга Вызова. Neutral к игрокам и к Стаду. NPC враждебной игроку фракции не открывает диалог, поэтому все, с кем говорят, сидят здесь.

У лагерных NPC: Faction = своя, галочка Attack hostile factions, Stats aggro 16. Очки фракции игроку даёт диалог «доклад» после квеста (Faction options в диалоге).

2. Клонер

Сохрани NPC с точным Display name — его же пиши в spawnClone(x, y, z, TAB, "Имя"). Одна вкладка, например tab 2:

Расставленным мобам и боссам: Stats → Respawn = Да, 3600 секунд. Это реальные секунды: время смерти пишется в NBT NPC, и если чанк выгружен, NPC возродится при следующей загрузке чанка. /forceload не нужен.

3. Сброс без смотрителя

Отдельного NPC, который держит весь данж, нет. Каждая часть сбрасывает себя сама и только тогда, когда рядом есть игроки:

  • Мобы и боссы — встроенный Respawn 3600.
  • Ворота арен и выход — died босса снимает завал, init босса ставит обратно. CNPC вызывает init из reset() при каждом возрождении. Ворота стоят в арене, рядом с боссом, поэтому когда игрок подходит к воротам, чанк босса уже загружен.
  • Головоломки и шорткаты — их Scripted Block пишет себе в storeddata время закрытия, а в tick (раз в 10 тиков, только в загруженном чанке) ставит блоки обратно, если рядом нет игроков.
  • Короткие последовательности (вентили, барабаны, тотемы) — world.getTempdata(). Сбрасываются скриптом или рестартом сервера.

Время везде — world.getTotalTime() (тики, 72000 = час). Оно стоит, пока сервер выключен, поэтому головоломки могут закрыться чуть позже мобов. На игру это не влияет.

var NpcAPI = Java.type("noppes.npcs.api.NpcAPI").Instance();

var GATE = [ [720, 60, 64], [721, 60, 64], [720, 61, 64], [721, 61, 64] ];
var GATE_BLOCK = "minecraft:polished_blackstone_bricks";
// Б1: имя второго босса. Ворота откроются, только когда мёртвы оба.
var PARTNER = "";

function init(e) {
    if (!e.npc.isAlive()) return;
    setGate(e.npc.getWorld(), true);
}

function died(e) {
    var npc = e.npc;
    var w = npc.getWorld();
    if (PARTNER != "" && partnerAlive(npc)) return;
    setGate(w, false);
    w.playSoundAt(npc.getPos(), "minecraft:block.iron_door.open", 3.0, 0.5);
    npc.say("§7Путь вниз открыт.");
}

function partnerAlive(npc) {
    var list = npc.getWorld().getNearbyEntities(npc.getPos(), 40, 2);
    var i;
    for (i = 0; i < list.length; i++) {
        if (String(list[i].getName()) == PARTNER && list[i].isAlive()) return true;
    }
    return false;
}

function setGate(w, closed) {
    var i;
    for (i = 0; i < GATE.length; i++) {
        var pos = NpcAPI.getIPos(GATE[i][0], GATE[i][1], GATE[i][2]);
        if (closed) w.setBlock(pos, GATE_BLOCK);
        else w.removeBlock(pos);
    }
}
Самозакрывающийся проход (Scripted Block: S1–S4, ворота загона, завалы головоломок) 
var NpcAPI = Java.type("noppes.npcs.api.NpcAPI").Instance();
var EntitiesType = Java.type("noppes.npcs.api.constants.EntitiesType");

var PLUG = [ [150, 65, 184], [150, 66, 184], [151, 65, 184], [151, 66, 184] ];
var PLUG_BLOCK = "minecraft:dark_oak_planks"; // только полные блоки
var CLOSE_AFTER = 72000;                      // тиков = 1 час
var SAFE_RADIUS = 12;
// Требование к предмету в главной руке; "" — без требования.
var NEED_ITEM = "";

function interact(e) {
    var w = e.block.getWorld();
    if (NEED_ITEM != "" && !holds(e.player, NEED_ITEM)) {
        e.player.message("§7Заперто.");
        return;
    }
    setPlug(w, false);
    e.block.getStoreddata().put("close_at", String(w.getTotalTime() + CLOSE_AFTER));
    w.playSoundAt(e.block.getPos(), "minecraft:block.wooden_door.open", 1.0, 0.8);
}

function tick(e) {
    var d = e.block.getStoreddata();
    if (!d.has("close_at")) return;
    var w = e.block.getWorld();
    if (w.getTotalTime() < Number(String(d.get("close_at")))) return;
    var p = PLUG[0];
    if (w.getNearbyEntities(NpcAPI.getIPos(p[0], p[1], p[2]), SAFE_RADIUS, EntitiesType.PLAYER).length > 0) return;
    setPlug(w, true);
    d.remove("close_at");
}

function holds(player, name) {
    var it = player.getMainhandItem();
    if (it == null || it.isEmpty()) return false;
    return String(it.getDisplayName()).indexOf(name) >= 0;
}

function setPlug(w, closed) {
    var i;
    for (i = 0; i < PLUG.length; i++) {
        var pos = NpcAPI.getIPos(PLUG[i][0], PLUG[i][1], PLUG[i][2]);
        if (closed) w.setBlock(pos, PLUG_BLOCK);
        else w.removeBlock(pos);
    }
}
Тайник (Scripted Block вместо сундука) 
var CACHE_ID = "a6_bolt";
var ITEM_ID = "minecraft:iron_ingot";
var ITEM_NAME = "§fЗасов загона";
var COOLDOWN = 72000;

function interact(e) {

    var pd = e.player.getStoreddata();
    var key = "hs_cache_" + CACHE_ID;
    var now = w.getTotalTime();
    if (pd.has(key) && now < Number(String(pd.get(key)))) {
        e.player.message("§7Пусто.");

function interact(e) {
    var w = e.block.getWorld();
    var it = e.player.getMainhandItem();
    if (it == null || it.isEmpty() || String(it.getDisplayName()).indexOf(HORN) < 0) {
        e.player.message("§7Барабан глухо молчит.");
        return;
    }
    var td = w.getTempdata();
    var now = w.getTotalTime();
    var seq = td.has("hs_drum_seq") ? String(td.get("hs_drum_seq")) : "";
    if (seq == "" || now - Number(td.get("hs_drum_start")) > 120) {
        seq = "";
        td.put("hs_drum_start", now);
    }
    seq += KEY;
    w.playSoundAt(e.block.getPos(), "minecraft:block.note_block.basedrum", 2.0, 0.6);
    if (CODE.indexOf(seq) != 0) {
        td.put("hs_drum_seq", "");

        w.spawnClone(202, 33, 80, TAB, "Унгор (призыв)");
        w.spawnClone(204, 33, 80, TAB, "Унгор (призыв)");
        return;
    }
    td.put("hs_drum_seq", seq);
    if (seq == CODE) {
        td.put("hs_drum_seq", "");
        setGate(w, false);
        td.put("hs_drum_close_at", now + 72000);
    }
}

function tick(e) {
    if (!MASTER) return;
    var w = e.block.getWorld();
    var td = w.getTempdata();
    if (!td.has("hs_drum_close_at") || w.getTotalTime() < Number(td.get("hs_drum_close_at"))) return;
    if (w.getNearbyEntities(NpcAPI.getIPos(GATE[0][0], GATE[0][1], GATE[0][2]), 12, EntitiesType.PLAYER).length > 0) return;
    setGate(w, true);
    td.remove("hs_drum_close_at");
}

function setGate(w, closed) {
    var i;

}

Гарракс: фазы + dash / weapon_spin (всё состояние — в storeddata самого Гарракса) 
var NpcAPI = Java.type("noppes.npcs.api.NpcAPI").Instance();
var AbilityAPI = Java.type("noppes.npcs.abilities.AbilityAPI");

var TAB = 2;
var STONE = [570, 12, 370];
var HEARTS = [ [570, 12, 236], [456, 12, 436], [684, 12, 436] ]; // свои координаты концов жёлобов
var CRYSTALS = [ [560, 12, 360], [580, 12, 360], [560, 12, 380], [580, 12, 380] ];
var EXIT = [ [762, 12, 448], [762, 13, 448] ];                 // barrier выхода и D4
var ARENA_R = 40;
var CAST_CD = 80;

function init(e) {
    var npc = e.npc;
    if (!npc.isAlive()) return;
    var d = npc.getStoreddata();
    if (d.has("base_speed")) npc.getAi().setWalkingSpeed(Number(String(d.get("base_speed"))));
    else d.put("base_speed", String(npc.getAi().getWalkingSpeed()));
    npc.getAi().setRetaliateType(0);
    npc.getDisplay().setSize(10);
    d.put("phase", "1");
    d.put("immune", "0");
    d.put("rite_broken", "0");
    d.put("rite_done", "0");
    d.put("cast_at", "0");
    d.put("wave_at", "0");
    setExit(npc.getWorld(), true);
}

function tick(e) {
    var npc = e.npc;
    if (!npc.isAlive()) { AbilityAPI.cancel(npc); return; }
    var d = npc.getStoreddata();
    var w = npc.getWorld();
    var now = w.getTotalTime();
    var hp = npc.getHealth() / npc.getMaxHealth();
    var ph = String(d.get("phase"));

    if (ph == "1" && hp <= 0.6) {
        AbilityAPI.cancel(npc);
        d.put("phase", "2");
        d.put("immune", "1");
        npc.getAi().setRetaliateType(3);
        npc.getAi().setWalkingSpeed(0);
        npc.setPosition(STONE[0], STONE[1], STONE[2]);
        var i;
        for (i = 0; i < HEARTS.length; i++) w.spawnClone(HEARTS[i][0], HEARTS[i][1], HEARTS[i][2], TAB, "Сердце жёлоба");
        d.put("wave_at", String(now + 200));
        npc.say("§4КРОВЬ — КАМНЮ!");
        return;
    }
    if (ph == "2") {
        if (countAlive(npc, "Сердце жёлоба") == 0) {
            d.put("immune", "0");
            d.put("phase", "2b");
            npc.getAi().setWalkingSpeed(Number(String(d.get("base_speed"))));
            npc.getAi().setRetaliateType(0);
            npc.say("§cЖёлобы пусты…");
            return;
        }
        if (now >= Number(String(d.get("wave_at")))) {
            if (countAlive(npc, "Гор (призыв)") < 6) {
                w.spawnClone(STONE[0] + 8, STONE[1], STONE[2], TAB, "Гор (призыв)");
                w.spawnClone(STONE[0] - 8, STONE[1], STONE[2], TAB, "Гор (призыв)");
            }
            d.put("wave_at", String(now + 200));
        }
        return;
    }
    if (ph == "2b" && hp <= 0.3) {
        d.put("phase", "3");
        npc.getDisplay().setSize(12);
        npc.addPotionEffect(PotionEffectType_STRENGTH, 60, 1, true);
        npc.addPotionEffect(PotionEffectType_RESISTANCE, 60, 0, true);
        var j;
        for (j = 0; j < CRYSTALS.length; j++) w.spawnClone(CRYSTALS[j][0], CRYSTALS[j][1], CRYSTALS[j][2], TAB, "Варп-кристалл");
        npc.say("§2Ночь Тайн пришла!");
        return;
    }
    if (ph == "3" && String(d.get("rite_done")) != "1") {
        var broken = String(d.get("rite_broken")) == "1" || countAlive(npc, "Варп-кристалл") == 0;
        if (broken) {
            d.put("rite_done", "1");
            npc.clearPotionEffects();
            npc.getDisplay().setSize(10);
            npc.setHealth(Math.max(1, npc.getHealth() - npc.getMaxHealth() * 0.15));
            npc.say("§cНЕТ! Камень… молчит…");
        }
    }

    if (AbilityAPI.isBusy(npc)) return;
    if (now < Number(String(d.get("cast_at")))) return;
    var t = npc.getAttackTarget();
    if (t == null || !t.isAlive()) return;
    if (Math.random() < 0.5) AbilityAPI.start(npc, "weapon_spin", t);
    else AbilityAPI.start(npc, "dash", t, AbilityAPI.params("chargeTicks", 20, "distance", 14.0));
    d.put("cast_at", String(now + CAST_CD));
}

function damaged(e) {
    if (String(e.npc.getStoreddata().get("immune")) == "1") e.setCanceled(true);
}

function died(e) {
    setExit(e.npc.getWorld(), false);
    e.npc.say("§7Камень трескается. Подъём Висельника свободен.");
}

function countAlive(npc, name) {
    var list = npc.getWorld().getNearbyEntities(npc.getPos(), ARENA_R, 2);
    var n = 0;
    var i;
    for (i = 0; i < list.length; i++) {
        if (String(list[i].getName()) == name && list[i].isAlive()) n++;
    }
    return n;
}

function setExit(w, closed) {
    var i;
    for (i = 0; i < EXIT.length; i++) {
        var pos = NpcAPI.getIPos(EXIT[i][0], EXIT[i][1], EXIT[i][2]);
        if (closed) w.setBlock(pos, "minecraft:barrier");
        else w.removeBlock(pos);
    }
}

  1. Четыре фракции. Лагеря: квестодатели, Trader, setSpawnpoint в interact.
