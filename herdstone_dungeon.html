Камень Расколотого Рога

Логово мятежного стада в Драквальде из четырёх локаций: Гнилая просека, Осквернённая крипта, Корневые глубины и Провал Камня Стада. Каждая локация — длинные переходы с отрядами и элитами, которые бьют больно и по-разному, и тесная арена с боссом, через которую лежит путь дальше. Ни один бой здесь не выигрывается бронёй и зельями: опасные удары снимают процент от максимального здоровья, боссы срывают с игроков эффекты, а урон по боссу ограничен за удар. Вход один, выход один, после последнего босса. Стадо враждебно и Порядку, и Разрушению, поэтому все квесты внутри данжа одинаковые для обеих сторон.

Лор

Где. Драквальд — тёмный лес между Мидденхеймом и Мидденландом, когда-то провинция Империи, а теперь охотничьи угодья стад Казрака Одноглазого. В чаще стоят руины монастыря Зигмара времён старой провинции.

Что случилось. Под руинами Стадо Расколотого Рога нашло обломок чёрного камня с прожилками варпа и сделало из него Камень Стада. Его вожак, думбулл Гарракс, решил, что Камень даст ему силу стать Повелителем Зверей. Он не стал склонять рога ни перед Казраком, ни перед вестниками Тёмных Богов. На Гехаймниснахт, Ночь Тайн, Гарракс хочет накормить Камень кровью, чтобы тот породил новых минотавров.

Почему это касается обеих сторон. Гарракс убивает всех, кто входит в чащу: людей, гномов, орков, чужие стада, избранных Хаоса. Сытый Камень даст ему армию, против которой не устоит ни Порядок, ни Разрушение. Поэтому внутри данжа цели у сторон одни и те же: убить Гарракса и его вожаков и сорвать обряд. Различаются только слова, которыми лагеря об этом говорят.

Монастырь, стадо и имена боссов придуманы для данжа. Драквальд, Казрак, Гехаймниснахт и все типы существ — каноничные.

Правила данжа

Бой решают механикиОпасные удары боссов и элит снимают долю от максимального здоровья через setHealth. Броня, «Защита», Сопротивление и золотые яблоки их не уменьшают. Боссы регулярно снимают с игроков все эффекты, урон по боссу ограничен за удар. Общая громкость урона и HP боссов — HS.DMG / ключ hs_dmg (см. Закон Стада, п. 9). Выживает тот, кто читает телеграфы и делает то, что требует механика.
Переходы — тоже бойМежду аренами — 40–170 блоков троп и коридоров шириной 6–8 блоков. На них стоят отряды по 3–4 моба и элиты. У каждого моба своя абилка с телеграфом, и удар по зазевавшемуся снимает 15–35% HP.
Арены тесныеБ1 — 44×38 блоков, Б2 — круг радиусом 20, Б3 — радиусом 21, Б4 — радиусом 26. Убежать от механики через всю арену нельзя. Тех, кто полез на стену или к выходу, поводок возвращает в круг с потерей 25% HP.
Один входВрата черепов на южной границе просеки. Граница — терновый декор и ряд minecraft:barrier. Барьер ставится один раз при постройке и больше не трогается.
Один выходВинтовая лестница колодца Б4 и проход к ней закрыты барьером. Его снимает died Гарракса и возвращает init при возрождении. Кольцо барьера вокруг устья не даёт спуститься с поверхности.
Арены — шлюзыПроход в следующую локацию начинается в арене босса. Завал снимает died босса и ставит init: CNPC вызывает init при каждом возрождении NPC.
Респаун 1 часВстроенный Respawn 3600 у всех мобов и боссов. Таймер считается в реальном времени и хранится в NBT NPC, возрождение — при загрузке чанка. Ни /forceload, ни NPC-смотритель не нужны.
Нет глобального состоянияСостояние хранится на самом боссе или блоке (storeddata, tempdata, таймеры NPC). Ключей в world storeddata, которые надо кому-то обнулять, нет.
Квесты универсальныеНи одна механика внутри данжа не привязана к фракции. Задания одни и те же, лагеря выдают их через разных NPC.

Закон Стада: общие правила боссов

Все боссы подключают общий файл hs_core.js (раздел CustomNPC). Он даёт восемь правил, которые делают бой одинаково опасным для группы в железе и для группы в незерите под зельями.

1. Потолок урона. В damaged: e.damage = min(e.damage, CAP) × множитель. CAP 12–14. Вне окна уязвимости множитель 0,25, в окне — 1, в фазе неуязвимости удар отменяется. После удара у NPC 10 тиков неуязвимости, поэтому вся группа вместе наносит боссу не больше ≈ 2×CAP в секунду. Решает не сила оружия, а то, сколько времени босс открыт.
2. Удары в процентах. hsStrike(p, 0.3) — минус 30% максимального HP через setHealth, мимо брони, «Защиты», Сопротивления и поглощения. Если удар добивает — hsKill: снять все эффекты, оставить 1 HP и добить MAGIC-уроном 100. Тотем бессмертия спасает один раз — это честно.
3. Рассеивание. Раз в 45–50 с босс снимает с игроков на арене все эффекты: Сопротивление, Силу, регенерацию, поглощение. Зелья держатся только до следующего рёва.
4. Телеграф перед каждым опасным ударом. Красный круг, конус или полоса TelegraphAPI горят 1,5–2 с, затем срабатывает удар по тем, кто остался внутри. Смерть в данже всегда означает «стоял в красном» или «не сделал механику».
5. Поводок. Игрок до 8 блоков за краем арены или выше пола на 4+ блока (столб, жемчуг на стену) переносится в центр и теряет 25% HP. Стрелять со стены и танцевать в дверях нельзя.
6. Сброс. 15 с без игроков на арене — npc.reset(): полное HP, фазы, ворота, адды убраны. Уйти с арены и вернуться к той же фазе нельзя.
7. Ярость. Через 6–10 минут боя босс раз в 10 с бьёт случайного игрока смертельным ударом. Затянуть бой регенерацией нельзя.
8. Масштаб по группе. На пуле maxHP = BASE × (0,7 + 0,3·N), где N — игроки на арене. Соло — 100%, вчетвером — 190%: из-за потолка урона четверо всё равно не убьют босса вчетверо быстрее.
9. Множитель урона и HP боссов. Одна переменная на весь данж: HS.DMG в hs_core.js (по умолчанию 1). Если в world storeddata есть ключ hs_dmg, он перекрывает файл — так можно крутить сложность, не переклеивая скрипт на каждом NPC. Множитель действует на все hsStrike (процентные удары мобов и боссов), на damage / damagePerTick абилок через hsStart и на max HP боссов: BASE × (0,7 + 0,3·N) × HS.DMG. Не трогает ярость (hsKill), автоатаку из GUI Stats, HP мобов переходов (они из вкладки Stats) и потолок урона по боссу. Примеры: 0,75 — легче, 1,25 — жёстче, 1,5 — очень жёстко. Лагеря и квесты

Оба лагеря стоят снаружи, на опушке у южной границы, по разные стороны от Перекрёстка. От Перекрёстка ведёт тропа к Вратам черепов. PvP между сторонами — настройка сервера, не CNPC. Лагеря бьют чужаков через фракции (Attack hostile factions) и дальность агро в Stats.

ПОРЯДОК

Застава Волчьего Брода

Юго-западная опушка. Квестодатель — Отто Рейнхардт (Dialog + Quest). Рядом NPC с ролью Trader (магазин). Кузнец — обычный NPC без роли, только декор и реплика. Респаун: в interact Отто вызывает player.setSpawnpoint(x, y, z) на кровать заставы.

«Если Камень наестся, к весне эта чаща дойдёт до стен Мидденхейма».

РАЗРУШЕНИЕ

Чёрный круг

Юго-восточная опушка. Квестодатель — Гурхак (тот же квест, другой диалог). Рядом Trader своей фракции. Респаун: setSpawnpoint в interact Гурхака.

«Гарракс забыл, кому служит. Принеси его рога — и Камень снова будет служить сильным».

Спираль локаций

Этажи не стоят друг под другом. Просека остаётся на месте входа. Крипта отзеркалена на восток, корневые глубины — ещё и на юг, провал Камня — на юг от просеки. Между пятнами пустая полоса, по ней идёт ступенчатый спуск. Колодец арены Б4 пробит до неба над самой ареной: из рощи видно небо, устье на поверхности закрыто кольцом барьера, вниз ведёт винт по кромке.

Скрипты боссов посчитаны для входа на Y 80 (пол провала на Y 8). Встал на другой высоте — прибавь разницу ко всем Y в ORIGIN.

Как собрать это в CustomNPC+

Ниже только то, что ставится руками в GUI и скриптах этой сборки. Скрипты — Nashorn: var и function, storeddata только строками. У каждого NPC в контейнере скриптов два файла: первый — hs_core.js (общий), второй — файл босса или моба. Глобальные function init/tick/timer из второго файла перекрывают одноимённые из первого, поэтому в ядре нет событий, только функции hs*. Командные блоки, /fill и /effect не нужны. Раскладка комнат и маркеров — tools/herdstone/herdstone_layout.py.

1. Фракции (Global → Factions)

  1. Порядок — дружественна игрокам Порядка, враждебна Разрушению и Стаду.
  2. Разрушение — наоборот.
  3. Стадо Расколотого Рога — враждебна обеим. Все мобы и боссы данжа.
  4. Нейтралы данжа — Шкрик и бестигоры Круга Вызова. Neutral к игрокам и к Стаду. NPC враждебной игроку фракции не открывает диалог, поэтому все, с кем говорят, сидят здесь.

У лагерных NPC: Faction = своя, галочка Attack hostile factions, Stats aggro 16. Очки фракции игроку даёт диалог «доклад» после квеста (Faction options в диалоге).

Расставленным мобам и боссам: Stats → Respawn = Да, 3600 секунд. Это реальные секунды: время смерти пишется в NBT NPC, и если чанк выгружен, NPC возродится при следующей загрузке чанка. /forceload не нужен. Return to start = да у боссов (после setPosition и reset() возвращаются в арену).

3. Сброс без смотрителя

Отдельного NPC, который держит весь данж, нет. Каждая часть сбрасывает себя сама и только тогда, когда рядом есть игроки:

  • Мобы и боссы — встроенный Respawn 3600. Бой на арене: 15 с без игроков — npc.reset() (ядро).
  • Ворота арен и выход — died босса снимает завал, init босса ставит обратно. CNPC вызывает init из reset() при каждом возрождении. В файле босса одна мировая точка ORIGIN (центр арены); завал — оффсеты GATE от неё.

Время везде — world.getTotalTime() (тики, 72000 = час). Оно стоит, пока сервер выключен. На игру это не влияет.

Маркеры строителя: pack — белая шерсть, elite — оранжевая, stake — бревно тёмного дуба, totem/menhir — блок кости, heart — редстоун, crystal — изумруд, herb — лаймовая шерсть, fog — зелёная, boss — красная. Колодец Б4 режется после всех комнат: воздух от верха стен D3 до y 255, винт из брёвен по кромке, кольцо барьера вокруг устья на высоте входа.

4. Скрипты

У каждого NPC в GUI Scripts добавь файлы в указанном порядке. В файле босса после постройки подставь одну мировую точку ORIGIN — центр арены (или оставь пустым: тогда берётся точка спауна NPC). Колья, тотемы, сердца, кристаллы, менгиры и завал — оффсеты [dx, dy, dz] от ORIGIN, их не пересчитывай. Задержки ударов — npc.getTimers().forceStart(id, тики, false) и событие timer: tick NPC идёт раз в 10 тиков.

Сложность крутится в одном месте: поле HS.DMG в первом файле (hs_core.js) или ключ world storeddata hs_dmg (перекрывает файл, пока сервер не перезапустят и ключ не сотрут). Он множит и исходящий урон (hsStrike / hsStart), и HP боссов на пуле. Автоатака и HP мобов переходов — из вкладки Stats, их множитель не трогает.

function hsBox(dx, dy, dz, w, h, d) {

        }
    }

// Общий множитель. Сначала world storeddata "hs_dmg" (живёт до рестарта/ручной смены),
// иначе HS.DMG из этого файла. Умножает исходящий урон и max HP боссов.
// hsKill / ярость / GUI-мили / потолок урона по боссу не трогает.
function hsScale(world) {
    var v = HS.DMG;
    if (world != null) {
        var d = world.getStoreddata();
        if (d.has("hs_dmg")) {
            var n = Number(String(d.get("hs_dmg")));
            if (n > 0) v = n;
        }
    }
    return v;
}

function hsStart(npc, id, target, params) {
    if (params != null) {
        var s = hsScale(npc.getWorld());
        var keys = ["damage", "damagePerTick"];
        var i;
        for (i = 0; i < keys.length; i++) {
            var k = keys[i];
            if (params.containsKey(k)) params.put(k, Number(params.get(k)) * s);
        }
        return AbilityAPI.start(npc, id, target, params);
    }
    return AbilityAPI.start(npc, id, target);
}

function hsBossHp(npc, nPlayers) {
    var n = nPlayers < 1 ? 1 : nPlayers;

// Удар в долях максимального HP. setHealth не режется бронёй, «Защитой», Сопротивлением и поглощением.

    pct = pct * hsScale(p.getWorld());

    p.setHealth(p.getHealth() - dmg);

}

// Линия от NPC по yaw: попадает ли игрок в полосу длиной len и полушириной half.
function hsOnLine(p, sx, sz, yaw, len, half) {
    var r = (yaw + 90) * Math.PI / 180;
    var fx = Math.cos(r), fz = Math.sin(r);
    var dx = p.getX() - sx, dz = p.getZ() - sz;
    var t = dx * fx + dz * fz;
    if (t < -1 || t > len) return false;
    return Math.abs(dx * fz - dz * fx) <= half;
}

// Вызывать первым в tick (раз в 10 тиков). Возвращает игроков на арене, если идёт бой, иначе null.
function hsFight(npc) {
    var now = hsNow(npc);
    var ps = hsPlayers(npc);
    var fightAt = hsNum(npc, "fight_at");
    if (fightAt == 0) {
        if (ps.length == 0 || npc.getAttackTarget() == null) return null;
        var hp = hsBossHp(npc, ps.length);
        npc.getStats().setMaxHealth(hp);
        npc.setHealth(hp);
        hsPut(npc, "fight_at", now);
        hsPut(npc, "dispel_at", now + HS.DISPEL_SEC * 20);
        return ps;
    }
    if (ps.length == 0) {
        var ea = hsNum(npc, "empty_at");
        if (ea == 0) hsPut(npc, "empty_at", now);
        else if (now - ea > HS.EMPTY_SEC * 20) npc.reset();
        return null;
    }
    hsPut(npc, "empty_at", 0);
    hsLeash(npc);
    if (now >= hsNum(npc, "dispel_at")) {
        hsDispel(npc, ps);
        hsPut(npc, "dispel_at", now + HS.DISPEL_SEC * 20);
    }
    if (now - fightAt > HS.ENRAGE_SEC * 20 && now >= hsNum(npc, "enrage_at")) {
        hsPut(npc, "enrage_at", now + 200);
        npc.say("§4Стадо не ждёт!");
        hsKill(hsRandom(ps));
    }
    return ps;
}

    }

    var n = (td.has(key) ? Number(String(td.get(key))) : 0) + 1;

}

function decayRend(npc, ps, now) {

        if (n <= 0 || now - Number(String(td.get("at_" + u))) < 60) continue;
        td.put("rend_" + u, String(n - 1));
        td.put("at_" + u, String(now));
    }
}

function timer(e) {
    var npc = e.npc;
    if (!npc.isAlive()) return;

    var i;

        if (hsCount(npc, HEART) == 0) return;
        npc.say("§4Камень напился. Вы — следующие.");
        for (i = 0; i < ps.length; i++) hsKill(ps[i]);
        return;
    }
    if (e.id == T_BRAND) {
        var b = npc.getWorld().getEntity(hsGet(npc, "brand_uuid", ""));
        if (b == null || !b.isAlive()) return;
        var share = hsPlayersAt(npc, b.getX(), b.getY(), b.getZ(), 3.0);
        for (i = 0; i < share.length; i++) hsStrike(share[i], 0.8 / share.length);
        return;
    }
    if (e.id == T_CIRCLES) {
        var pts = hsGet(npc, "circles", "").split(";"), empty = 0;
        for (i = 0; i < pts.length; i++) {
            var xz = pts[i].split(":");
            if (xz.length < 2) continue;
            if (hsPlayersAt(npc, Number(xz[0]), npc.getY(), Number(xz[1]), 2.0).length == 0) empty++;
        }
        if (empty == 0) return;
        npc.say("§2Камень пьёт из пустых кругов!");
        for (i = 0; i < ps.length; i++) hsStrike(ps[i], 0.6 * empty);
        return;
    }
    if (e.id != T_HIT) return;
    var kind = hsGet(npc, "hit", ""), ox = hsNum(npc, "hit_x"), oz = hsNum(npc, "hit_z"), yaw = hsNum(npc, "hit_yaw");
    for (i = 0; i < ps.length; i++) {
        var p = ps[i];
        if (kind == "spin" && hsFlat(p, npc.getX(), npc.getZ()) <= 4.5) hsStrike(p, 0.25);
        if (kind == "dash" && hsOnLine(p, ox, oz, yaw, 14, 1.8)) hsStrike(p, 0.35);
        if (kind == "cone" && hsFlat(p, ox, oz) <= 9 && Combat.isInFrontCone(ox, oz, yaw, p, 30.0)) hsStrike(p, 0.6);
    }
}

function interact(e) {

        e.player.message("§7Шкалу крутит только креатив.");
        return;
    }
    var d = e.block.getWorld().getStoreddata();
    var cur = d.has("hs_dmg") ? Number(String(d.get("hs_dmg"))) : 1;
    var i, next = STEPS[0];
    for (i = 0; i < STEPS.length; i++) {
        if (Math.abs(STEPS[i] - cur) < 0.001) {
            next = STEPS[(i + 1) % STEPS.length];
            break;
        }
    }
    d.put("hs_dmg", String(next));
    e.player.message("§eУрон и HP боссов ×" + next);
}
