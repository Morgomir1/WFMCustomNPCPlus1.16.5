Камень Расколотого Рога

Логово мятежного стада в Драквальде из четырёх локаций: Гнилая просека, Осквернённая крипта, Корневые глубины и Провал Камня Стада. Каждая локация заканчивается ареной с боссом, и только через неё можно пройти дальше. Вход один, выход один, после последнего босса. Стадо враждебно и Порядку, и Разрушению, поэтому все квесты внутри данжа одинаковые для обеих сторон.

Лор

Где. Драквальд — тёмный лес между Мидденхеймом и Мидденландом, когда-то провинция Империи, а теперь охотничьи угодья стад Казрака Одноглазого. В чаще стоят руины монастыря Зигмара времён старой провинции.

Что случилось. Под руинами Стадо Расколотого Рога нашло обломок чёрного камня с прожилками варпа и сделало из него Камень Стада. Его вожак, думбулл Гарракс, решил, что Камень даст ему силу стать Повелителем Зверей. Он не стал склонять рога ни перед Казраком, ни перед вестниками Тёмных Богов. На Гехаймниснахт, Ночь Тайн, Гарракс хочет накормить Камень кровью, чтобы тот породил новых минотавров.

Почему это касается обеих сторон. Гарракс убивает всех, кто входит в чащу: людей, гномов, орков, чужие стада, избранных Хаоса. Сытый Камень даст ему армию, против которой не устоит ни Порядок, ни Разрушение. Поэтому внутри данжа цели у сторон одни и те же: убить Гарракса и его вожаков и сорвать обряд. Различаются только слова, которыми лагеря об этом говорят.

Монастырь, стадо и имена боссов придуманы для данжа. Драквальд, Казрак, Гехаймниснахт и все типы существ — каноничные.

Правила данжа

Один входВрата черепов на южной границе просеки. Граница — терновый декор и ряд minecraft:barrier (ставит смотритель из списка координат). Входа в CNPC для «невидимой стены» нет.
Один выходПодъём Висельника открывается только из арены последнего босса после его смерти. Снаружи в него не войти.
Арены — шлюзыПроход в следующую локацию начинается в арене босса. Ворота открываются после смерти босса и закрываются, когда он возрождается.
Респаун 1 часЧерез час возрождаются все мобы и боссы, а головоломки, вода, ворота и шорткаты сбрасываются. Делает это NPC-«смотритель».
Шорткаты не обходят боссовВсе шорткаты ведут внутри одной локации: от прихожей арены назад к началу локации. Срезают мобов и головоломки, но не арены.
Квесты универсальныеНи одна механика внутри данжа не привязана к фракции. Задания одни и те же, лагеря выдают их через разных NPC.

Лагеря и квесты

Оба лагеря стоят снаружи, на опушке у южной границы, по разные стороны от Перекрёстка. От Перекрёстка ведёт тропа к Вратам черепов. PvP между сторонами — настройка сервера, не CNPC. Лагеря бьют чужаков через фракции (Attack hostile factions) и дальность агро в Stats.

ПОРЯДОК

Застава Волчьего Брода

Юго-западная опушка. Квестодатель — Отто Рейнхардт (Dialog + Quest). Рядом NPC с ролью Trader (магазин). Кузнец — обычный NPC без роли, только декор и реплика. Респаун: в interact Отто вызывает player.setSpawnpoint(x, y, z) на кровать заставы.

«Если Камень наестся, к весне эта чаща дойдёт до стен Мидденхейма».

РАЗРУШЕНИЕ

Чёрный круг

Юго-восточная опушка. Квестодатель — Гурхак (тот же квест, другой диалог). Рядом Trader своей фракции. Респаун: setSpawnpoint в interact Гурхака.

«Гарракс забыл, кому служит. Принеси его рога — и Камень снова будет служить сильным».

В Global → Quests заведи один квест на цель (Type: Kill, имя цели = имя Display босса, например «Грул Кабанья Рука»). В диалоге Отто и в диалоге Гурхака укажи этот же квест (Dialog → Quest). Сплошная линия — маршрут. Красные ромбы — арены, через которые лежит переход между локациями. Бирюзовый пунктир — шорткаты, все внутри своих локаций. Чёрный пунктир — единственный выход.

Локация 2 · Осквернённая крипта

Склепы монастыря, разорённые стадом: надгробия разбиты, на стенах рога и знаки Хаоса, через потолок проросли корни, половина этажа затоплена. Локация про головоломки и переговоры. Попасть сюда можно только из арены Б1, выйти — только через арену Б2.

B2 Головоломка: три вентиля

Зал может быть с водой как декор (статика). Проходы к B3 и B4 закрыты тремя решётками. Три Scripted Block (V1, V2, V3): в storeddata блока ключ id = 1/2/3. ПКМ дописывает id в world storeddata valves. Порядок 2 → 1 → 3 (подсказка на табличках-надгробиях). Каждый верный шаг: removeBlock своей решётки (5–8 координат). Неверный: обнулить valves, вернуть все решётки setBlock(..., "minecraft:iron_bars"), spawnClone «Гор» ×2. Слив целого зала водой в CNPC не делается.

B3 Головоломка: тотемы Тёмных Богов

Четыре Scripted Block. ПКМ крутит storeddata god по кругу: K → N → T → S. Имя блока в чат/табличка рядом показывает текущий знак. Невидимый NPC у решётки B5 в tick раз в 8 с делает say строк молитвы (порядок богов = ответ). Когда все четыре совпали с кодом — снять блоки реликвария, внутри сундук с Тотемным амулетом.

B4 Притвор: Шкрик

NPC Шкрик, фракция нейтральная, Role нет, Dialog включён. Availability опции «накормить»: у игрока есть Гнилой окорок. В dialogOption: removeItem окорока, say подсказки, открыть S2 (removeBlock решётки). Убить — обычная смерть, респаун 3600. Запасной рычаг S2 — Scripted Block в B1 (под водой-декором).

Локация 3 · Корневые глубины

Земляные пещеры, сквозь которые идут корни толщиной с дом: dark oak wood, мицелий, шрумлайты, костные блоки. Чем ниже, тем больше зелёного свечения варпа. Локация про ритм, выживание в тумане и большую арену. Вход из арены Б2, выход через арену Б3.

C2 Головоломка: зов стада

Четыре Scripted Block-барабана, в storeddata ключ L/R/B. Scripted Item «Рог Бра-шамана»: ПКМ пишет world storeddata hornBlown=1 и звук. Пока рог не трубили — барабаны в interact только пишут игроку сообщение. Ритм за 6 с (120 тиков): L L R B. Ошибка — spawnClone «Унгор» ×3 (на них тот же скрипт маски, что у вышек). Успех — снять решётки ворот списком координат.

C3 Варп-топь

Невидимый неуязвимый NPC «Туман» стоит в топи. В tick: игроки в радиусе (EntitiesType.PLAYER). Если у игрока storeddata hs_clean_until ещё не истек — пропуск. Иначе addPotionEffect тошнота 3 с и иссушение 2 с (это секунды). Четыре Scripted Block «святая трава»: ПКМ пишет игроку hs_clean_until = now + 300. Зона урона мода здесь не используется: она не умеет пропускать «чистых» игроков.

C4 Секрет: Топь Бормочущего

Тупик, дальше данжа нет. Четыре менгира — обычные блоки камня. Раз в 12 с босс в tick берёт игроков в радиусе 15. Кто дальше 2.5 блока от любого менгира — тошнота, слепота, замедление на 6 с. Укрытие проверяется дистанцией, не линией взгляда.

Локация 4 · Провал Камня Стада

Огромная карстовая воронка, над которой виден клочок ночного неба. Внутри подземная роща: искривлённые деревья, каменные круги, костры. В центре стоит Камень Стада: crying obsidian, зелёное стекло, свет снизу. Вход из арены Б3. Единственный выход из всего данжа — Подъём Висельника, который открывается в арене Б4.

D1 Пиршество минотавров

Четыре клона «Минотавр», в init AI → On Attack = Ничего (setRetaliateType(3)), пока world storeddata hs_feast не 1. Варианты:

  • Паркур — балка под потолком (блоки, без скрипта).
  • Окорох — Scripted Block стола: забрать окорок, 20 с держать минотавров в режиме Ничего, затем hs_feast=1 и всем setRetaliateType(0). Драки минотавров друг с другом в CNPC нет (одна фракция).
  • Бой — ударить любого: в damaged выставить hs_feast=1 и мстить всем четырём. Сундук — ваниль после зачистки или дроп с последнего.

D2 Круг Вызова

Восемь клонов «Бестигор», один с Dialog «Право Вызова». Опция принять: скрипт ставит кольцо barrier (список координат), остальным семи On Attack = Ничего, чемпион — Мстить. В died чемпиона: снять barrier, семерым тоже Ничего (расступились). Опция отказаться / ударить любого: всем восьми Мстить, барьеры не ставить. После победы Scripted Block спускает лестницу S4.

Боссы

Цифры на 2–3 игроков в железе/алмазе; для соло делите HP на 1,6. Каждый босс — NPC в клонере, Advanced → Respawn 3600, фракция «Стадо Расколотого Рога». Модель — Display этой сборки (GeckoLib Custom Model). Вкладка Scripts: вставь скрипт с tick/died/damaged. Рывок и круговой удар — id абилок мода dash и weapon_spin (вкладка Scripts, AbilityAPI.start). Остальное — клоны, диалоги и storeddata.

Б1 · A4 Загон · ворота в локацию 2

Грул Кабанья Рука и Кровохряк

Два отдельных NPC на арене (наездника в CNPC для боя не ставим). Кровохряк: размер 8, HP 260, мили. Грул: размер 6, HP 180, мили. Клоны: «Кровохряк», «Грул Кабанья Рука».
  1. Кровохряк. Скрипт: пока жив и есть цель — AbilityAPI.start(npc, "dash", target, AbilityAPI.params("chargeTicks", 20, "distance", 14.0, "damage", 12.0)) с кулдауном по getTotalTime. Колья в загоне — только декор.
  2. Грул. При HP ≤ 50% один раз spawnClone четырёх «Унгор» (флаг в storeddata). В died Грула и кабана: если второго уже нет — открыть спуск (список removeBlock).

Дроп: шкура / клык — слоты дропа в Inventory NPC.

Б2 · B5 Святилище · ворота в локацию 3

Мургрот Туманный Глас, бра-шаман

Размер 5, HP 220. Рендж: в GUI Inventory предмет в слот снаряда, Stats дальность > 8. AI On Attack = Ничего, чтобы стоял и стрелял.
  1. Четыре тотема. Клоны «Тотем Мургрота», HP 60, не двигаются (walking speed 0, On Attack = Ничего). В tick Мургрота: если в радиусе арены жив хоть один тотем (по имени/тегу) — в damaged setCanceled(true). Раз в 10 с setPosition на координаты ближайшего живого тотема.
  2. ≤ 60% HP. Один раз за бой: spawnClone трёх «Мургрот-копия» (HP 1). Если у игрока в инвентаре предмет с именем «Тотемный» — копиям addPotionEffect(PotionEffectType_GLOWING, 30, 0, false) (30 секунд). Игрокам в арене слепота 4 с.
  3. ≤ 25% HP. Один раз: spawnClone «Унгор» ×4. Случайному игроку Weakness и Slowness 8 с.

Дроп: Рог Бра-шамана (кость с именем, Scripted Item). died открывает шахту вниз.

Б3 · C5 Яма · ворота в локацию 4

Великая Утроба, Горгон

Размер 12, HP 480, мили. Рядом комната «Утроба» (отдельный объём) и три точки спавна клона «Нерв» (HP 20, не двигается).
  1. Глоток раз в 20 с: ближайший игрок в 6 блоках → setPosition в Утробу, заспавнить 3 «Нерв», запомнить UUID в world storeddata. Горгону On Attack = Ничего. Скрипт нерва в died: счётчик −1; при 0 вернуть игрока в яму, Горгону Slowness 6 с и снова Мстить.
  2. Кормушка. Четыре Scripted Block. ПКМ с окороком: removeItem, 8 с Горгону Ничего (стоит). Игроки бьют в спину обычным уроном.
  3. ≤ 30% HP. getAi().setWalkingSpeed ×1,5 (базу сохранить строкой). Каждые ~8 с AbilityAPI.start(npc, "jump_slam", target).

Дроп: рог Горгона. died открывает Глотку.

Б4 · D3 Роща · финал и выход

Гарракс Расколотый Рог, думбулл

Размер 10, HP 900, двуручный топор в руках. Фазы в storeddata "1" / "2" / "3".
  1. 100–60%. Чередовать weapon_spin и dash (кулдаун по world time). Один каст одновременно (AbilityAPI.isBusy).
  2. 60–30%. setPosition на Камень, в damaged отмена урона. Каждые 10 с spawnClone «Гор» ×2, иногда «Минотавр». Три клона «Сердце жёлоба» (HP по вкусу). Их died увеличивает channels. При 3 — снять неуязвимость.
  3. ≤ 30%. getDisplay().setSize(12), Strength II и Resistance I на 60 с. Срыв: Scripted Block Камня + Рог в руке или четыре клона «Варп-кристалл» (HP 80); в tick кристалла world.thunderStrike раз в 5 с по своей позиции. При роге или 4 смертях — снять баффы размером обратно, отнять 15% HP.

Дроп: топор и рога в Inventory. died снимает barrier с D4 и выхода.

Шорткаты

Как собрать это в CustomNPC+

Ниже только то, что ставится руками в GUI и скриптах этой сборки. Скрипты — Nashorn: var и function, storeddata только строками. В начале файла: var NpcAPI = Java.type("noppes.npcs.api.NpcAPI").Instance(); и при необходимости EntitiesType, AbilityAPI. Командные блоки, /fill и /effect не нужны.

1. Фракции (Global → Factions)

  1. Порядок — дружественна игрокам Порядка, враждебна Разрушению и Стаду.
  2. Разрушение — наоборот.
  3. Стадо Расколотого Рога — враждебна обеим. Все мобы и боссы данжа.
  4. Нейтралы данжа — Шкрик. Neutral ко всем, чтобы горы его не били.

У лагерных NPC: Faction = своя, галочка Attack hostile factions, Stats aggro 16. Очки фракции игроку даёт диалог «доклад» после квеста (Faction options в диалоге).

2. Клонер

Сохрани NPC с точным Display name — его же пиши в spawnClone(x, y, z, TAB, "Имя"). Одна вкладка, например tab 2:

3. Смотритель

Невидимый неуязвимый NPC в загруженном чанке, фракция нейтральная, не агрится. Скрипт на вкладке Scripts. Раз в час (метка world.getTotalTime() в storeddata) он:

  • если в радиусе любой из четырёх арен есть игрок — откладывает сброс на 1200 тиков;
  • иначе ставит обратно решётки, калитки, barrier выхода, лестницы S4, затор S3;
  • обнуляет world storeddata: valves, hornBlown, channels, riteBroken, hs_feast.

Мобы сами встанут по Respawn 3600. Большую воду не сбрасываем — её в головоломке нет.

Смотритель (вставь на NPC) 
var NpcAPI = Java.type("noppes.npcs.api.NpcAPI").Instance();
var EntitiesType = Java.type("noppes.npcs.api.constants.EntitiesType");

var HOUR = 72000;
var NEXT_KEY = "hs_next_reset";
var ARENAS = [ [626, 70, 98, 30], [430, 52, 434, 20], [262, 30, 384, 22], [570, 10, 370, 30] ];
var BARS = [ [720, 60, 64], [721, 60, 64] ]; // свои координаты решёток спуска Б1

function init(e) {
    var d = e.npc.getStoreddata();
    var now = e.npc.getWorld().getTotalTime();
    if (!d.has(NEXT_KEY)) d.put(NEXT_KEY, String(now + HOUR));
}

function tick(e) {
    var npc = e.npc;
    var w = npc.getWorld();
    var d = npc.getStoreddata();
    var now = w.getTotalTime();
    if (now < getInt(d, NEXT_KEY)) return;
    if (busy(w)) { d.put(NEXT_KEY, String(now + 1200)); return; }
    var i;
    for (i = 0; i < BARS.length; i++) w.setBlock(BARS[i][0], BARS[i][1], BARS[i][2], "minecraft:iron_bars", 0);
    var sd = w.getStoreddata();
    sd.put("valves", "");
    sd.put("hornBlown", "0");
    sd.put("channels", "0");
    sd.put("riteBroken", "0");
    sd.put("hs_feast", "0");
    d.put(NEXT_KEY, String(now + HOUR));
    w.broadcast("§2Лес шевелится. Стадо вернулось.");
}

function busy(w) {
    var i;
    for (i = 0; i < ARENAS.length; i++) {
        var a = ARENAS[i];
        if (w.getNearbyEntities(NpcAPI.getIPos(a[0], a[1], a[2]), a[3], EntitiesType.PLAYER).length > 0) return true;
    }
    return false;
}

function getInt(data, key) {
    if (!data.has(key)) return 0;
    return parseInt(String(data.get(key)));
}

    var t = e.entity;

    try {

var CODE = "LLRB";
var GATE = [ [290, 34, 200], [291, 34, 200] ];

function interact(e) {
    var w = e.block.getWorld();
    var td = w.getTempdata();
    var sd = w.getStoreddata();
    if (String(sd.get("hornBlown")) != "1") {
        e.player.message("§7Барабан глухо молчит.");
        return;
    }
    var now = w.getTotalTime();
    var seq = td.get("drumSeq") || "";
    if (seq == "" || now - (td.get("drumStart") || 0) > 120) {
        seq = "";
        td.put("drumStart", now);
    }
    seq += String(e.block.getStoreddata().get("key"));
    w.playSoundAt(e.block.getPos(), "minecraft:block.note_block.basedrum", 2.0, 0.6);
    if (CODE.indexOf(seq) != 0) {
        td.put("drumSeq", "");
        w.spawnClone(200, 33, 80, 2, "Унгор");
        return;
    }
    td.put("drumSeq", seq);
    if (seq == CODE) {
        var i;
        for (i = 0; i < GATE.length; i++) w.removeBlock(GATE[i][0], GATE[i][1], GATE[i][2]);
    }
}

Гарракс: фазы + dash / weapon_spin 
var AbilityAPI = Java.type("noppes.npcs.abilities.AbilityAPI");

var STONE = [570, 12, 370];
var PHASE = "hs_g_phase";
var IMMUNE = "hs_g_immune";
var WAVE = "hs_g_wave";
var TAB = 2;

function init(e) {
    var d = e.npc.getStoreddata();
    d.put(PHASE, "1");
    d.put(IMMUNE, "0");
    e.npc.getWorld().getStoreddata().put("channels", "0");
    e.npc.getWorld().getStoreddata().put("riteBroken", "0");
}

function tick(e) {
    var npc = e.npc;
    if (!npc.isAlive()) { AbilityAPI.cancel(npc); return; }
    var d = npc.getStoreddata();
    var w = npc.getWorld();
    var now = w.getTotalTime();
    var hp = npc.getHealth() / npc.getMaxHealth();
    var ph = String(d.get(PHASE));

    if (ph == "1" && hp <= 0.6) {
        AbilityAPI.cancel(npc);
        d.put(PHASE, "2");
        d.put(IMMUNE, "1");
        npc.setPosition(STONE[0], STONE[1], STONE[2]);
        npc.say("§4КРОВЬ — КАМНЮ!");
        d.put(WAVE, String(now + 200));
        return;
    }
    if (ph == "2" && getInt(w.getStoreddata(), "channels") >= 3) {
        d.put(IMMUNE, "0");
        d.put(PHASE, "2b");
    }
    if ((ph == "2b" || ph == "2") && hp <= 0.3) {
        d.put(PHASE, "3");
        npc.getDisplay().setSize(12);
        npc.addPotionEffect(PotionEffectType_STRENGTH, 60, 1, true);
        npc.addPotionEffect(PotionEffectType_RESISTANCE, 60, 0, true);
        npc.say("§2Ночь Тайн пришла!");
    }
    if (String(d.get(PHASE)) == "3" && String(w.getStoreddata().get("riteBroken")) == "1") {
        w.getStoreddata().put("riteBroken", "0");
        npc.getDisplay().setSize(10);
        npc.setHealth(npc.getHealth() - npc.getMaxHealth() * 0.15);
        npc.say("§cНЕТ! Камень… молчит…");
    }
    if (String(d.get(PHASE)) == "2" && now >= getInt(d, WAVE)) {
        w.spawnClone(STONE[0] + 8, STONE[1], STONE[2], TAB, "Гор");
        w.spawnClone(STONE[0] - 8, STONE[1], STONE[2], TAB, "Гор");
        d.put(WAVE, String(now + 200));
        return;
    }
    if (String(d.get(IMMUNE)) == "1") return;
    if (AbilityAPI.isBusy(npc)) return;
    var t = npc.getAttackTarget();
    if (t == null || !t.isAlive()) return;
    if (Math.random() < 0.5) AbilityAPI.start(npc, "weapon_spin", t);
    else AbilityAPI.start(npc, "dash", t, AbilityAPI.params("chargeTicks", 20, "distance", 14.0));
}

function damaged(e) {
    if (String(e.npc.getStoreddata().get(IMMUNE)) == "1") e.setCanceled(true);
}

function getInt(data, key) {
    if (!data.has(key)) return 0;
    return parseInt(String(data.get(key)));
}

Порядок работ

  1. Три фракции. Лагеря: квестодатели, Trader, setSpawnpoint в interact.
  2. Пять Kill-квестов, по два диалога (Отто / Гурхак) на каждый, Completion Instant.
  3. Терновая стена + barrier. Каркас локаций. Решётки на выходах из арен — сразу.
  4. Клоны из таблицы, Respawn 3600, сохранить в cloner tab 2.
  5. Scripted Block: вентили, тотемы, барабаны, трава, кормушки, калитки, Камень, выход.
  6. Скрипты боссов и унгоров. Смотритель. /forceload на чанки данжа.
  7. Проход за Порядок и за Разрушение. Смерть на арене → шорткат. Час ожидания → сброс ворот при пустой арене и откладывание, если стоишь внутри.
